Boarding Accounts

How to Start an Application

Using the Employee Portal, start by finding the Operations tab at the top, select Boarding Accounts. This is where you will find all resources you need to start filling out a Merchant Processing Agreement.

Merchant Processing Agreement Pre-Application

Important things to note during this step:

  • Make sure to complete the equipment section and uploading documents before sending for signature
  • Any Clover menu builds need to be attached in the merchant application in the document section
